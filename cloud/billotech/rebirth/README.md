# Billo Rebirth

Two records in, the third one out. Lives at `/billotech/rebirth/`.

- `index.html` - the tool page: player with live meters, stem solo, source DNA, casting, reference lyrics, and the on-device Rebirth lab (drop two songs, get the blueprint).
- `audio/` - STAY THROWED master (256k MP3) and five stems. Original instrumental, no samples.
- `engine/make_track.py` - builds the whole track from code: `python3 make_track.py out` (numpy, scipy, soundfile, pyloudnorm). 83 BPM, E minor, -9 LUFS, -1 dB ceiling.
- `engine/source_dna.json` - what was measured on Get Throwed and Still Throwed.

Not done yet: vocals (needs a singer/rapper or a vocal generator), and Billy's own voice on the breakdown (Higgsfield was at 0 credits; the page uses the device voice).
