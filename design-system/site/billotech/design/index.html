How it works

Change one file. Ship every page.

1 · TokensOne source file

Every value lives in tokens.json: raw values, the roles they fill, and each skin.

2 · BuildGenerated, never hand-edited

build.py writes the stylesheet and locks it with a fingerprint. Same version, different output: refused.

3 · VersionEvery release keeps its folder

Pages load /assets/billo-glass/2.0.0/. Upgrading or rolling back is one number.

4 · GateLint before ship

lint.py fails any page that hard-codes colors or fonts, and the audit re-reads the live site.

<html data-skin="glass">
<link rel="stylesheet" href="/assets/billo-glass/2.0.0/billo-glass.css">
